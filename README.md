# Agenda Manicura

Aplicación Android offline para gestionar clientas, servicios, citas, propinas e ingresos de un salón de manicura.

## Abrir el proyecto

Abre esta carpeta en Android Studio y deja que sincronice Gradle. Requiere JDK 17 y Android SDK 35. Después ejecuta la configuración `app` en un emulador o teléfono con Android 8 (API 26) o posterior.

## Funciones incluidas

- Calendario mensual con citas y símbolos de manicura/pedicura.
- Clientas, catálogo de servicios, duración y precio base.
- Citas con precio personalizado por servicio, propinas, notas y protección contra solapes.
- Estados pendiente, cobrada y cancelada; los ingresos solo suman las cobradas.
- Notificación diaria local configurable (09:00 inicialmente) con las citas pendientes del día.
